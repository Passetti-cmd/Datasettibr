# Data Setti - Company Website

> **Note:** This was my first HTML project, representing an early business idea I had for a company focused on data intelligence and automation.

## 📋 About This Project

This is a professional website for **Data Setti**, a company that provides data intelligence, AI solutions, automation services, and business insights. The website was built as my first HTML project and represents an early entrepreneurial vision.

### 🎯 Company Vision

Data Setti was conceived as a company that helps businesses:

- **Transform data into intelligent decisions** through AI and analytics
- **Automate processes** to reduce costs and increase efficiency
- **Gain strategic insights** with interactive dashboards and reports
- **Implement intelligent inventory management** systems
- **Leverage growth marketing** strategies based on data

## 🚀 Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI/UX**: Clean, professional interface with smooth animations
- **Interactive Carousels**: Showcase projects and customer testimonials
- **Contact Form**: Integrated form submission with FormSubmit
- **Performance Optimized**: Fast loading times and optimized assets
- **SEO Friendly**: Proper meta tags and semantic HTML structure

## 🛠️ Technologies Used

- **HTML5**: Semantic markup
- **CSS3**: Modern styling with CSS variables and animations
- **JavaScript (ES6+)**: Interactive functionality with professional logging
- **GSAP**: Advanced animations and scroll triggers
- **Typed.js**: Animated typing effect for hero section
- **Font Awesome**: Icon library
- **Google Fonts**: Poppins font family
- **Google Analytics**: Traffic and user behavior tracking
